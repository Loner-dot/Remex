# ⚡ SHADOW SYNDICATE - Clan Platform

A cinematic cyberpunk clan management platform built for mobile-first use.

## 🎮 Features
- Password-based member login system
- Admin dashboard for member management
- Aura Scanner with shareable results
- Profile Card Generator
- Anonymous Confession System
- Clan Leaderboard
- Cyberpunk/Anime aesthetic
